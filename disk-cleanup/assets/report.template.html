常见问题

点了「删除」会发生什么？能反悔吗？

增强模式下：文件先移入废纸篓（和手动拖进废纸篓一样，随时能拖回来），确认没问题后再清空废纸篓真正释放空间。勾选「彻底删除」则跳过废纸篓直接删除。少数「命令型」条目（清空废纸篓、brew 清理、清理旧临时文件）会直接执行、不经过废纸篓——弹窗里会单独列出。所有删除动作都记录在同目录的 清理记录.log 里。删除前请退出对应 App（微信、Chrome、VS Code…），避免数据库损坏。

为什么需要「启动清理报告.command」？

浏览器有安全沙箱：纯网页永远不可能直接删你电脑上的文件（否则随便一个恶意网页就能清空你的硬盘）。所以报告配了一个只监听本机(127.0.0.1)的小服务器：它只认报告里列出的白名单动作，网页发「删某一项」的编号，它来执行。不用时关掉终端窗口即可。没启动它时报告照常能看，删除按钮退化为生成终端命令。

微信数据到底怎么清？

分三层：① 纯缓存（内置浏览器缓存/日志/下载残留）——退出微信后直接删，绝不碰聊天记录；② 聊天媒体（图片/视频/文件）——点开明细能看到按月份/按会话的分布，勾选旧月份删（聊天记录文字还在，但历史媒体文件会打不开且服务器不补发，删前先另存重要的）；③ 聊天数据库——绝对不能删。也可以用微信自带 设置→通用→存储空间。

Docker 虚拟磁盘怎么清？

那是一个虚拟磁盘文件（Docker.raw），所有镜像/容器/卷都打包在里面，直接删文件会损坏 Docker。正确姿势：启动 Docker Desktop → Troubleshoot → Clean / Purge data；或终端 docker system prune -a。清完后稀疏磁盘会自动收缩。

废纸篓和 iPhone 备份为什么「大小未知」？

被 macOS 隐私保护（TCC）挡住了。想统计：系统设置 → 隐私与安全性 → 完全磁盘访问权限 → 把「终端」加进去。iPhone 备份管理入口：访达边栏选手机 → 管理备份。
